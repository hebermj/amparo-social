# Busca Web exclusiva na Instância SearXNG Própria (fim do fallback comunitário)

Quando o usuário faz um Pedido de Atividade, a Busca Web consulta **exclusivamente** a Instância SearXNG Própria do operador — um contêiner Docker dedicado em casa, exposto via Tailscale Funnel com HTTPS e protegido por autenticação basic no Caddy, com credencial que só o Amparo conhece. As instâncias comunitárias da SearXNG foram removidas do código: além de ignorarem o parâmetro `language=pt-BR`, a instância default devolvia resultados irrelevantes e em chinês/japonês (Chrome Web Store, Zhihu, receitas). Se a Instância Própria estiver indisponível, a Recomendação sai só da Base de Atividades — nunca de instâncias públicas. Trade-off aceito: a resiliência do fallback comunitário (ADR-0004) é sacrificada em troca de qualidade, idioma e segurança dos resultados. O acesso é restrito ao bot via `Authorization: Basic`; o `search.js` ainda descarta resultados em scripts não-latinos como defesa em profundidade.
